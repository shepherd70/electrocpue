# Example electrofishing catch records

A simulated long-format multi-pass electrofishing dataset for four
reaches, each surveyed on two dates, with two species and three removal
passes per survey. Counts were generated from a constant- probability
removal (binomial depletion) model so that depletion estimators recover
sensible abundances. Pairs with
[example_reach](https://shepherd70.github.io/electrocpue/reference/example_reach.md).

## Usage

``` r
example_catch
```

## Format

A data frame with 48 rows and 8 columns:

- reach_id:

  Reach identifier (character), e.g. `"R01"`.

- date:

  Survey date (Date).

- pass_number:

  Removal pass index, 1-3 (integer).

- species:

  Species code (character): `"BNT"` or `"RBT"`.

- count:

  Number of fish captured on the pass (integer).

- effort_seconds:

  Shocking effort for the pass, in seconds (numeric).

- amperage:

  Mean shocking current for the pass, in amperes (numeric).

- voltage:

  Mean shocking voltage for the pass (numeric).

## Details

Generated by `data-raw/make_example_data.R` with `set.seed(42)`.
