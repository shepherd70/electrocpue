# Example reach metadata

Reach-level metadata for the four reaches in
[example_catch](https://shepherd70.github.io/electrocpue/reference/example_catch.md),
keyed by `reach_id`.

## Usage

``` r
example_reach
```

## Format

A data frame with 4 rows and 7 columns:

- reach_id:

  Reach identifier (character), e.g. `"R01"`.

- length_m:

  Reach length in metres (numeric).

- mean_width_m:

  Mean wetted width in metres (numeric).

- habitat_class:

  Dominant habitat class (character).

- crew:

  Survey crew (character).

- gear:

  Electrofishing gear (character).

- area_m2:

  Surveyed area in square metres, `length_m * mean_width_m` (numeric).

## Details

Generated by `data-raw/make_example_data.R`.
